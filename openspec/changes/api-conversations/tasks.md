# Tasks: API de conversaciones (`api-conversations`)

Fases secuenciales; cada una empieza cuando la anterior pasa su gate. Comportamiento en `specs/conversations-api/spec.md` y `specs/flows-api/spec.md`; cómo, en `design.md` (D1-D16 y «Contrato de API»). Cada `#### Scenario` de los dos deltas tiene un `it` con exactamente su título (lo comprueba `test/spec-coverage.spec.ts`, 3.10). Ningún fichero nuevo lleva en el nombre `credentials` ni `apikey` (los bloquea `guard_files`), y ninguno es un fichero de entorno. Ningún test llama a la API de Anthropic. Fuera de los ficheros de D1, `git diff --stat main...HEAD` no lista nada. Un gate solo se marca con checks realmente ejecutados. **Ojo**: desde el commit de la spec, `pnpm check` está en rojo en esta rama por un único test, `test/spec-coverage.spec.ts` → «Errores de las conversaciones» (escenario del delta de `flows-api` sin su `it`, medido el 2026-10-17); los gates de las fases 1 y 2 lo admiten como único fallo y se cierra en 3.9.
